# MoneyPrinter

Режет стримы, сериалы и фильмы на короткие яркие клипы для YouTube Shorts / TikTok.
Находит смешные и «виральные» моменты, нарезает их на фрагменты (по умолчанию
минимум 60 секунд — для сериалов/фильмов) и конвертирует в вертикальный формат
9:16. Клипы вырезаются целыми смысловыми блоками — не по клочку, а законченной
мыслью. Умеет автоматически генерировать хештеги и выкладывать в TikTok с
отложенной публикацией по расписанию.

Полностью бесплатный и локальный: никаких платных API.

## Как это работает

Гибрид дешёвых эвристик и локальных AI-моделей:

1. **Анализ аудио** (numpy): энергетика (громкость + всплески), тишина для аккуратных границ.
2. **Детекция сцен** — PySceneDetect или встроенный scene-фильтр ffmpeg.
3. **Транскрипция** — локальный faster-whisper (CTranslate2, ~4x быстрее openai-whisper
   при том же качестве): находим реплики со смехом (`ха-ха`, `lol`, `😂`),
   возбуждением (`wow`, `ничего себе`), восклицаниями, капсом.
   Сегменты склеиваются в «мысли»: пауза больше `--story-gap` (2 сек) или смена сцены — граница.
4. **Скоринг** каждой «мысли»-кандидата: энергия + текст + опционально локальная LLM (Ollama)
   ранжирует «виральность». Пересекающиеся клипы подавляются.
5. **Нарезка** ffmpeg: топ-N клипов, вертикаль 9:16 (размытый фон или кадрирование).

## Установка

```bash
# ffmpeg обязателен
brew install ffmpeg            # macOS
sudo apt install ffmpeg        # Linux

python3 -m venv .venv
source .venv/bin/activate

pip install -e ".[all]"        # с faster-whisper + детекцией сцен
# или минимально: pip install -e .
```

Для AI-ранжирования (необязательно): установите [Ollama](https://ollama.com) и `ollama pull llama3.2`.

Скорость: транскрипция на faster-whisper (в ~4 раза быстрее openai-whisper, то же качество),
на CPU длинные ролики транскрибируются параллельно по чанкам (по ядрам, --jobs),
клипы нарезаются параллельно, ffmpeg декодирует через аппаратное ускорение
(`-hwaccel auto`). На NVIDIA GPU всё автоматически идёт на CUDA — ещё быстрее.

## Использование

```bash
# базово: 10 вертикальных клипов (мин. длина 60с для сериалов/фильмов)
moneyprinter process video.mp4 -o clips

# больше контроля
moneyprinter process video.mp4 \
  --max-clips 15 \
  --max-duration 45 \
  --min-duration 60 \
  --story-gap 2 \              # пауза-граница между репликами, сек
  --whisper-model small \     # tiny/base/small/medium/large
  --language ru \             # язык транскрипции
  --llm llama3.2 \            # AI-ранжирование моментов и хештеги
  --crop                      # кадрирование вместо размытого фона
  --horizontal                # не конвертировать в 9:16

# метаданные видео
moneyprinter probe video.mp4
```

Результат — папка с клипами `clip_XX_*.mp4` (9:16, 1080×1920, нумерация
строго по хронометражу) и отчётами `report.json` / `report.csv`
(включая сгенерированные хештеги и подпись).

## Автопостинг в TikTok (экспериментально)

> ⚠️ TikTok не даёт публичного API для автопостинга. Реализовано через
> браузерную автоматизацию (Playwright) и **нарушает ToS TikTok** — используйте
> на свой страх и риск, с умеренной частотой.

```bash
pip install -e ".[upload]"     # + Playwright
playwright install chromium

# 1) один раз войти и сохранить cookies (откроется браузер — залогиньтесь по QR)
moneyprinter login

# 2) нарезать и сразу поставить в очередь: первый клип — сразу,
#    остальные — каждые 2 часа (--schedule-interval, сек)
moneyprinter process video.mp4 --schedule --schedule-interval 7200

# или вручную добавить готовые клипы в очередь
moneyprinter publish clips/ --queue --schedule-interval 5400

# 3) два варианта держать расписание:
#
# 3a) долгий процесс в tmux/screen (сам будит себя):
#     moneyprinter run-schedule --schedule-interval 7200
#
# 3b) НЕ держать программу постоянно — пусть системный планировщик
#     будит `publish-next` каждые 2 часа (macOS launchd / Linux cron /
#     Windows Task Scheduler):
moneyprinter install-scheduler --schedule-interval 7200
#   убрать автозапуск: moneyprinter uninstall-scheduler
#   вручную «опубликовать следующий»: moneyprinter publish-next
```

Хештеги под каждый клип генерируются автоматически: базовый набор
(`#shorts #тикток #фильм …`) плюс тематические — от локальной LLM (`--llm`)
либо эвристикой по ключевым словам текста клипа. Состояние очереди
сохраняется в JSON, переживает перезапуск: опубликованное не повторяется.

При варианте 3b программа **не висит в памяти 24/7** — системный планировщик
просыпает `moneyprinter publish-next` раз в `interval` секунд; тот публикует
ровно один «наступивший» клип и завершается. При ошибке публикации клип
остаётся «due», чтобы планировщик повторил попытку при следующем просыпании.
Поддерживаются macOS, Linux и **Windows** (через `schtasks`).

> ⚠️ Для Windows: Playwright запускает Chromium в фоновом режиме; убедитесь,
> что аккаунт, под которым работает задача, имеет доступ к cookies-файлу
> (`%USERPROFILE%\.moneyprinter\tiktok_cookies.json`).

## Режим «сериал → микро-серии»

Для сериалов/фильмов, которые нужно выкладывать **подряд по порядку** как
продолжение (одна серия сериала = набор микро-роликов в TikTok `Часть 1/12`,
`2/12`, …). В этом режиме нет отбора по «виральности» — видео режется
последовательно на равные части заданной длины.

```bash
moneyprinter serial серия01.mp4 \
  --series-title "Уроки химии" \
  --episode 1 \
  --part-duration 60 \            # длина одной микро-серии, сек
  --base-hashtag урокихимии \     # свои теги (можно несколько раз)
  --base-hashtag химия \
  --schedule --schedule-interval 7200   # сразу в очередь: 1-я сразу, дальше каждые 2ч
```

Каждая микро-серия получает подпись вида
`Уроки химии | Серия 1 | Часть 3` (без `N/Y`) и **уникальное описание по содержанию**
(крючок-интрига из транскрипции — через LLM `--llm` или эвристику), плюс
автотеги по названию + тематике части + базовый набор. Описания **не повторяются**
между частями, т.к. берутся из реального текста каждого куска.

```bash
moneyprinter serial серия01.mp4 \
  --series-title "Уроки химии" --episode 1 --part-duration 60 \
  --whisper-model base --language ru \
  --llm llama3.2 \                  # описание-интрига от локальной LLM
  --base-hashtag урокихимии --base-hashtag химия \
  --schedule --schedule-interval 7200
```

Доступны `--start`/`--end` (резать кусок), `--max-parts` (лимит частей),
`--no-audio-desc` (не транскрибировать — описания без крючка по содержанию),
`--horizontal`/`--crop`, `--jobs`.

Хештеги и описания: в базовый набор входят самые популярные реальные теги
TikTok (`#fyp #foryou #viral #trending #shorts` и др.), плюс по теме видео
добавляются популярные теги из курируемого списка (детектив, химия, спорт и т.п.)
через LLM или эвристику. Описание — короткий крючок по сюжету + эмодзи +
«Смотри до конца.» (генерится LLM по тексту либо эвристикой).

Вывод в консоли очищен от служебного шума (предупреждения HuggingFace о симлинках/токенах, логи faster-whisper) - видны только прогресс и статус.

Отчёт `report.json` (+ `report.csv`) создаётся **сразу при запуске** и
**дописывается после каждого клипа**. Если нажать Ctrl+C или программа упадёт
в середине — в отчёте уже будут все успевшие нарезаться части (поле
`partial: true`), так что данные не теряются.

Все нарезки складываются в одну контейнерную папку **`cuts/`**, а внутри —
по сериалам и эпизодам: `cuts/<Название сериала>/S<NN>/`
(например `cuts/Уроки химии/S01/`). Папка берётся из `--series-title` и
`--episode` автоматически, если не задан явный `-o`. Так сериалы, фильмы и
прочее лежат вместе, но не смешиваются между собой:

```bash
moneyprinter serial серия01.mp4 --series-title "Уроки химии" --episode 1 ...   # → Уроки химии/S01/
moneyprinter serial серия02.mp4 --series-title "Уроки химии" --episode 2 ...   # → Уроки химии/S02/
moneyprinter serial другой.mp4 --series-title "Иной детектив" --episode 1 ...  # → Иной детектив/S01/
```

Для `regen-captions` та же логика: при дефолтном `-o clips` папка выводится
как `<Название>/S<NN>/`.

Перегенерация описаний для **уже нарезанных** клипов (без повторной нарезки):
```bash
moneyprinter regen-captions серия01.mp4 -o clips \
  --series-title "Уроки химии" --episode 1 --language ru --llm llama3.2
```
Читает `clips/report.json`, заново транскрибирует исходник и переписывает
caption+хештеги каждого клипа. Удобно, если поменяли промпт LLM или название.

## Улучшение качества видео (`enhance`)

Telegram, TikTok и Instagram повторно пережимают видео — если исходник «слабый»,
после пересжатия картинка становится ещё хуже. Команда `enhance` делает видео
максимально чётким для повторной публикации: апскейл, шумоподавление и резкость
через ffmpeg (без тяжёлых AI-зависимостей).

```bash
# Один файл → enhanced/имя_файла_enhanced.mp4 (улучшение до 1080p)
moneyprinter enhance input.mp4

# Папка — все видео из неё обрабатываются параллельно
moneyprinter enhance clips/ -o enhanced/ --jobs 4

# Под свои параметры
moneyprinter enhance input.mp4 \
  --target-width 1920 --target-height 1080 \  # целевое разрешение (1080p)
  --crf 18 \          # качество, меньше = лучше (18 = высокое)
  --preset slow \     # медленнее = лучшее сжатие
  --denoise-strength 3 \  # сила шумоподавления (0 = выкл)
  --sharpen-strength 1.5 \    # сила резкости (0 = выкл)
  --sharp-mode unsharp \      # unsharp (безопасный, default) | cas | both | off
```

**Ориентация сохраняется автоматически** — вертикальное видео (1080x1920, как
клипы Shorts) останется вертикальным и не будет сплющено, содержимое не
искажается (force_original_aspect_ratio). Принудительный формат — флаг
`--no-preserve-aspect`.

Резкость по умолчанию (`unsharp`) шарпит **только яркость**, цветовые каналы
(хрому) не трогает — поэтому не появляется цветных ореолов/артефактов
(«красные/зелёные кривые линии») даже на пережатых в соцсетях видео.
Режим `cas`/`both` даёт чуть более агрессивную резкость, но на некоторых
исходниках может вносить цветные артефакты — включайте осознанно.

Используются фильтры: `hqdn3d` (шумоподавление) → `unsharp` (резкость по
яркости) → `scale` с интерполятором `lanczos` (высококачественный апскейл).
Кодирование — `libx264`, `yuv420p`, `+faststart` для быстрой потоковой загрузки.

### AI-апскейл (опционально, GPU)

Для супер-разрешения можно использовать **Real-ESRGAN**: сперва каждый кадр
апскейлится нейросетью, затем ffmpeg доводит до целевого размера и резкости.

```bash
moneyprinter enhance input.mp4 --ai      # через realesrgan-ncnn-vulkan
```

Нужен установленный бинарник `realesrgan-ncnn-vulkan` в PATH
(https://github.com/xinntao/Real-ESRGAN-ncnn-vulkan). Если его нет — команда
предупредит и предложит отключить `--ai`.

### Улучшение прямо при нарезке

Добавьте флаг `--enhance` к `serial`/`process`, и каждый клип будет улучшен
сразу после нарезки:

```bash
moneyprinter serial серия01.mp4 --series-title "Уроки химии" --enhance
moneyprinter process видео.mp4 --enhance
```

Ход обработки показывается прогресс-барами в консоли:
`Сцены` — декодирование видеоряда, `Нарезка` — единый бар через все клипы.

## Структура

```
moneyprinter/
  cli.py        # CLI (argparse)
  pipeline.py   # оркестрация пайплайна
  audio.py      # громкость, тишина, всплески
  scenes.py     # детекция смены сцен
  transcribe.py # Whisper-транскрипция
  score.py      # скоринг/ранжирование кандидатов
  cutting.py    # нарезка + вертикаль 9:16
  hashtags.py   # генерация хештегов и подписи
  upload.py     # загрузка в TikTok (Playwright)
  scheduler.py  # очередь отложенных публикаций
  media.py      # обёртки ffmpeg/ffprobe
  models.py     # дата-классы
 tests/          # pytest
```
