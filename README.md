# MoneyPrinter

Режет стримы, сериалы и фильмы на короткие яркие клипы для YouTube Shorts / TikTok.
Находит смешные и «виральные» моменты, нарезает их на фрагменты (по умолчанию
минимум 60 секунд — для сериалов/фильмов) и конвертирует в вертикальный формат
9:16. Клипы вырезаются целыми смысловыми блоками — не по клочку, а законченной
мыслью. Умеет автоматически генерировать хештеги и выкладывать в TikTok с
отложенной публикацией по расписанию.

Полностью бесплатный и локальный: никаких платных API.

## Как это работает

Гибрид дешёвых эвристик и локальных AI-моделей:

1. **Анализ аудио** (numpy): энергетика (громкость + всплески), тишина для аккуратных границ.
2. **Детекция сцен** — PySceneDetect или встроенный scene-фильтр ffmpeg.
3. **Транскрипция** — локальный faster-whisper (CTranslate2, ~4x быстрее openai-whisper
   при том же качестве): находим реплики со смехом (`ха-ха`, `lol`, `😂`),
   возбуждением (`wow`, `ничего себе`), восклицаниями, капсом.
   Сегменты склеиваются в «мысли»: пауза больше `--story-gap` (2 сек) или смена сцены — граница.
4. **Скоринг** каждой «мысли»-кандидата: энергия + текст + опционально локальная LLM (Ollama)
   ранжирует «виральность». Пересекающиеся клипы подавляются.
5. **Нарезка** ffmpeg: топ-N клипов, вертикаль 9:16 (размытый фон или кадрирование).

## Установка

```bash
# ffmpeg обязателен
brew install ffmpeg            # macOS
sudo apt install ffmpeg        # Linux

python3 -m venv .venv
source .venv/bin/activate

pip install -e ".[all]"        # с faster-whisper + детекцией сцен
# или минимально: pip install -e .
```

Для AI-ранжирования (необязательно): установите [Ollama](https://ollama.com) и `ollama pull llama3.2`.

Скорость: транскрипция на faster-whisper (в ~4 раза быстрее openai-whisper, то же качество),
на CPU длинные ролики транскрибируются параллельно по чанкам (по ядрам, --jobs),
клипы нарезаются параллельно, ffmpeg декодирует через аппаратное ускорение
(`-hwaccel auto`). На NVIDIA GPU всё автоматически идёт на CUDA — ещё быстрее.

## Использование

```bash
# базово: 10 вертикальных клипов (мин. длина 60с для сериалов/фильмов)
moneyprinter process video.mp4 -o clips

# больше контроля
moneyprinter process video.mp4 \
  --max-clips 15 \
  --max-duration 45 \
  --min-duration 60 \
  --story-gap 2 \              # пауза-граница между репликами, сек
  --whisper-model small \     # tiny/base/small/medium/large
  --language ru \             # язык транскрипции
  --llm llama3.2 \            # AI-ранжирование моментов и хештеги
  --crop                      # кадрирование вместо размытого фона
  --horizontal                # не конвертировать в 9:16

# метаданные видео
moneyprinter probe video.mp4
```

Результат — папка с клипами `clip_XX_*.mp4` (9:16, 1080×1920, нумерация
строго по хронометражу) и отчётами `report.json` / `report.csv`
(включая сгенерированные хештеги и подпись).

## Автопостинг в TikTok (экспериментально)

> ⚠️ TikTok не даёт публичного API для автопостинга. Реализовано через
> браузерную автоматизацию (Playwright) и **нарушает ToS TikTok** — используйте
> на свой страх и риск, с умеренной частотой.

```bash
pip install -e ".[upload]"     # + Playwright
playwright install chromium

# 1) один раз войти и сохранить cookies (откроется браузер — залогиньтесь по QR)
moneyprinter login

# 2) нарезать и сразу поставить в очередь: первый клип — сразу,
#    остальные — каждые 2 часа (--schedule-interval, сек)
moneyprinter process video.mp4 --schedule --schedule-interval 7200

# или вручную добавить готовые клипы в очередь
moneyprinter publish clips/ --queue --schedule-interval 5400

# 3) два варианта держать расписание:
#
# 3a) долгий процесс в tmux/screen (сам будит себя):
#     moneyprinter run-schedule --schedule-interval 7200
#
# 3b) НЕ держать программу постоянно — пусть системный планировщик
#     будит `publish-next` каждые 2 часа (macOS launchd / Linux cron /
#     Windows Task Scheduler):
moneyprinter install-scheduler --schedule-interval 7200
#   убрать автозапуск: moneyprinter uninstall-scheduler
#   вручную «опубликовать следующий»: moneyprinter publish-next
```

Хештеги под каждый клип генерируются автоматически: базовый набор
(`#shorts #тикток #фильм …`) плюс тематические — от локальной LLM (`--llm`)
либо эвристикой по ключевым словам текста клипа. Состояние очереди
сохраняется в JSON, переживает перезапуск: опубликованное не повторяется.

При варианте 3b программа **не висит в памяти 24/7** — системный планировщик
просыпает `moneyprinter publish-next` раз в `interval` секунд; тот публикует
ровно один «наступивший» клип и завершается. При ошибке публикации клип
остаётся «due», чтобы планировщик повторил попытку при следующем просыпании.
Поддерживаются macOS, Linux и **Windows** (через `schtasks`).

> ⚠️ Для Windows: Playwright запускает Chromium в фоновом режиме; убедитесь,
> что аккаунт, под которым работает задача, имеет доступ к cookies-файлу
> (`%USERPROFILE%\.moneyprinter\tiktok_cookies.json`).

Ход обработки показывается прогресс-барами в консоли:
`Сцены` — декодирование видеоряда, `Нарезка` — единый бар через все клипы.

## Структура

```
moneyprinter/
  cli.py        # CLI (argparse)
  pipeline.py   # оркестрация пайплайна
  audio.py      # громкость, тишина, всплески
  scenes.py     # детекция смены сцен
  transcribe.py # Whisper-транскрипция
  score.py      # скоринг/ранжирование кандидатов
  cutting.py    # нарезка + вертикаль 9:16
  hashtags.py   # генерация хештегов и подписи
  upload.py     # загрузка в TikTok (Playwright)
  scheduler.py  # очередь отложенных публикаций
  media.py      # обёртки ffmpeg/ffprobe
  models.py     # дата-классы
 tests/          # pytest
```
